# Youtube-Clone
Built a YouTube clone using HTML and CSS with a clean homepage UI, navbar, sidebar, and video section layout. Currently improving the project by adding responsiveness and more interactive features as part of my frontend learning journey.

## Status
🚧 Work in Progress  
Currently adding:
- Responsive design
- More UI improvements
- Additional sections/features

## What I Learned

While building this project, I improved my understanding of:
- HTML structure
- CSS styling
- Flexbox layouts
- UI design replication

## Challenges I Faced

The most difficult part for me was understanding:
- CSS Grid
- Flexbox positioning
- Arranging elements properly on the page
- Thinking about layouts in a grid/box structure

At first, it was confusing to understand how items align and fit together, but while building this project I started understanding layouts much better through practice.
